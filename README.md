# C++ Postfix Expression Evaluator

Evaluates reverse Polish notation with a custom C++ stack and deque.

Course project for UC Davis ECS 36C, Winter 2025, Homework 2. Includes course-provided scaffolding.

## Build

```sh
make
```

Originally published in [`cpp-postfix-calculator`](https://github.com/371619924/cpp-postfix-calculator).
